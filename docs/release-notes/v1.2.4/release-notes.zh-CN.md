# PrimiGenius 1.2.4

本次汇总近期主程序的编辑器、导出、自由市场、文件预览和运行流程更新。分析插件仍通过插件商店和自由市场独立安装、更新。

## 矢量编辑与快捷操作

- 渐变色标支持在色条上选中、拖动，单独调整颜色、位置和不透明度，减少重复的色标位置列表。
- 矩形、正方形、椭圆和多边形归入同一工具集，右键展开选择；移除自由绘制铅笔工具。
- 完善钢笔、曲率钢笔及锚点操作，支持路径预览、节点编辑和矢量布尔运算。
- 矩形及支持的凸多边形提供画布内圆角控制点，支持拖动、键盘调整、撤销和重做；修复移动图形时控制点留在原地的问题。
- 按住 Shift 拖动可锁定水平或垂直移动，支持多选整体移动；松开后恢复自由移动，保留 Shift 单击增减选区。
- 单独轻按 Ctrl 可返回选择工具；Ctrl+Z 撤销上一步，Ctrl+Y 或 Ctrl+Shift+Z 重做，修复部分工具栏焦点和大小写导致快捷键失效的问题。
- 从标尺拖出的辅助线可选中，并使用 Delete、Backspace 或删除按钮移除，支持撤销和重做。
- 统一快捷属性栏控件高度及文字垂直对齐；移除高级功能中的版面功能入口。
- 完善对象与图层、精确变换、分组隔离、操作历史，以及未保存修改提示和编辑恢复。
- 指针更新按帧合并，圆角计算限制在当前对象，拖动过程中不生成整图历史快照。

## 原生格式导出与预览

- 完善 TIF、PNG、SVG、PDF 四种格式的实际编码与导出。TIF 写入真实 TIFF 数据及物理 DPI；SVG、PDF 保留可用的矢量路径和文字，原有位图仍作为位图保存。
- 修复提高 DPI 后文件大小估计不变的问题，按格式显示实际或合理估算的大小，并同步计算输出像素尺寸。
- 修复部分导入图片在预览和导出时变成破图占位符的问题，将图片资源内嵌到导出内容；缺失资源时提示错误并阻止错误导出。
- 减少切换 DPI 时的重复资源请求，限制预览尺寸及超大导出的内存分配，并避免旧预览覆盖新设置。
- 保留 Cairo SVG 的有效内部字形引用，兼容轮廓字形显示、导出和重新打开；继续拦截危险或无效引用。

## 自由市场与插件安装

- 根据本地版本、来源和所有者区分“安装”“更新”“已安装”“本地版本较新”等状态；相同版本和较新版本不再重复下载、替换。
- 修复鼠标停在“已安装”按钮上持续显示等待光标的问题，完善安装进度、失败反馈和重试状态。
- 支持查看提交源码、目录树、版本历史和修改内容，长文件使用连续滚动和分段加载，并改善中英文显示。
- 改善旧版插件源码预览的下载加速、缓存和清理，保留签名及完整性校验。
- 为具有相应权限的审核者提供待审核数量、入口和提醒。
- 通用 ZIP 校验兼容 Windows 反斜杠路径及归档开头的 `./`，继续拒绝路径穿越和不安全条目，并完善大插件安装的空间检查。

## 文件预览、日志与运行流程

- 改善大文本、FASTA 及注释类文本文件的连续读取与长行显示，明确视觉折行不会修改原始文件，减少额外的整文件扫描。
- 优化预览内容的分段渲染、滚动和资源清理，改善工作流输出定位。
- 为 R 和工作流运行生成独立输出目录，并在成功或失败响应中返回实际目录；完善运行日志汇总和导出归属。
- 修复已验证的 R 环境因镜像标识比较错误而重复执行工具链检查的问题，新增 R 包加载提示。大型绘图包每次新进程加载的耗时仍然存在。
- 完善运行环境状态刷新、日志持久化和已有环境迁移处理；旧 R 环境清理时检查引用及进行中的写入任务，占用时延后处理。
